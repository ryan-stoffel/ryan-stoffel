CS senior concentrating in AI/ML, currently building software for defense systems at NSWC Corona. I like problems that live close to the metal, a WebSocket relay here, a NixOS build there, an ESP32 arguing with a cloud API, and I care most about backend and systems work that's correct, fast, and built to last.

### Notable Projects

**WISSv5 Agent** — an AI assistant that helps operators troubleshoot hardware and software in the WISS defense platform through plain-language chat. Built on the ZeroClaw runtime, packaged in a self-configuring NixOS VM.

**SnapDose** — a three-platform Type 1 Diabetes management system: React Native app, Spring Boot API on GCP, and a custom ESP32 insulin-pump simulator.
