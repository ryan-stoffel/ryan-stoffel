CS senior concentrating in AI/ML, currently building software for defense systems at NSWC Corona. I like problems that live close to the metal — a WebSocket relay here, a NixOS build there, a hand-rolled protocol reverse-engineered from someone else's source — and I care most about backend and systems work that's correct, fast, and built to last.

### Notable Projects

**WISSv5 Agent** — an AI operator-assistant integrated into a naval range scoring platform, built on the Zeroclaw runtime and packaged as a self-configuring, offline-installable NixOS VM. Sole author of the agent gateway: WebSocket command relay, reverse-engineered hardware protocols, a skill platform, and a nightly self-reflection loop.

**SnapDose** — a three-platform Type 1 Diabetes management system: React Native app, Spring Boot API on GCP, and a custom ESP32 insulin-pump simulator. Led a five-person team for Junior Design.

**Bogey Busters** — a Flutter/Supabase/PostGIS golf round-tracking app, built with a partner.

**FOD Hunter** — a YOLO/Unity computer vision project for detecting foreign object debris on an aircraft carrier deck.
